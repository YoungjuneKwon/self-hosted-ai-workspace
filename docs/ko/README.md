# self-hosted-ai-workspace

AI 코딩 에이전트가 **머무는 기계**를 스크립트 하나로 세웁니다. 닫으면 잊어버리는
채팅 창 대신에요.

English: [../../README.md](../../README.md)

---

## 호텔인가, 집인가

호텔은 좋은 거래입니다. 가면 바로 열리고, 매일 누가 치워 주고, 배관 걱정을 할 일이
없습니다. 여행이라면 호텔이 정답이고 집을 사는 쪽이 어리석은 선택입니다.

그런데 호텔 방에는 내 것을 둘 수가 없습니다. 체크아웃하면 방은 비워집니다. 벽에 못을
박을 수 없습니다. 귀중품은 프런트가 조합을 아는 금고에 맡깁니다.

클라우드 AI 작업환경은 호텔이고, 좋은 호텔입니다. 이 저장소는 **여행을 끝내고 거기서
살기 시작한 사람들**을 위한 것입니다. 매일 에이전트와 일하다가, 아침마다 빈 방에서
다시 시작하고 있다는 걸 알아차린 사람들 말입니다.

## 차이가 실제로 무엇인가

| | 오픈AI 클라우드 | 앤트로픽 클라우드 | 이 작업환경 |
|---|:---:|:---:|:---:|
| 내가 통제하는 하드웨어에서 실행 | X | X | O |
| 세션이 끝나도 맥락이 남는다 | △ | △ | O |
| 데스크톱·브라우저 제어 | △ | △ | O |
| 자격 증명과 권한 | X | △ | O |
| 작업 중에 UI 를 만들어 붙인다 | X | △ | O |
| **내가 자는 동안에도 돈다** | **O** | **O** | **X** |
| 데이터가 둔 자리에 남는다 | X | X | O |
| 비용을 예측할 수 있다 | △ | △ | O |

`O` 직접 지원 · `△` 부분적이거나 제약이 있음 · `X` 불가

굵은 줄을 다시 보십시오. **그 칸은 클라우드가 이깁니다. 접전도 아닙니다.** 호텔에는
발전기가 있고 내 집에는 없습니다. 기계가 꺼져 있으면 에이전트도 꺼져 있습니다. 나머지
일곱 줄이 집을 가질 이유라면, 그 한 줄은 호텔도 계속 쓸 이유입니다. 대부분의 사람은
그래야 합니다.

각 줄의 근거를 적은 긴 글: [why-this-exists.md](why-this-exists.md).

## 무엇이 들어 있나

재시작해도 남는 홈 디렉터리를 가진 데비안 컨테이너입니다.

- **Node 22, Python 3.11, git, gh, ripgrep, jq** — 에이전트가 당연히 있다고 가정하는 바닥
- **Claude Code**, 선택적으로 **opencode** 와 **Codex CLI**
- **[ValetFS](https://github.com/WinM2M/valet-fs)** — API 키는 폰에 두고, 컨테이너에는
  메모리로만, 허용하는 동안만 빌려줍니다. 체크섬과 서명을 확인한 뒤 설치합니다.
- 바인드 마운트된 `workspace/` — 코드는 내 디스크에 있고 컨테이너는 버려도 되는 것이 됩니다

## 빠른 시작

도커가 필요합니다. 윈도우라면 WSL2 백엔드를 켠 Docker Desktop 입니다.

```sh
git clone https://github.com/YoungjuneKwon/self-hosted-ai-workspace
cd self-hosted-ai-workspace
./bootstrap.sh
```

스크립트는 환경을 점검하고, 이미지를 빌드하고, 컨테이너를 띄웁니다. 도커와 실행한
디렉터리 밖은 건드리지 않습니다.

```sh
./bootstrap.sh --help         # 전체 옵션
./bootstrap.sh --no-valetfs   # 금고 없이
./bootstrap.sh --grant-vault  # 아래의 허가 질문에 미리 답하고 시작
./bootstrap.sh --shell        # 이미 만든 작업환경에 셸로 들어가기
```

컨테이너 안에서는

```sh
claude            # 한 번 로그인하면 세션이 볼륨에 남습니다
valetfs --help    # 실제 키를 쓸 준비가 되면 폰과 연결합니다
```

## 부트스트랩이 묻는 한 가지

컨테이너를 띄우기 전에 스크립트가 멈춰서, **에이전트가 매번 묻지 않고 `valetfs exec`
를 불러도 되는지** 물어봅니다. 허가 범위가 `exec`·`ls`·`status` 이고 `cat` 은
일부러 빠져 있다는 것까지 설명한 뒤 답을 기다립니다.

**정하지 않고 묻는 이유**는, 에이전트가 제 뜻대로 금고를 열 수 있으면 디스크에 둔 키와
별 차이가 없기 때문입니다. **나중에 명령을 치라고 떠넘기지 않는 이유**는, 사람 몫이어야
하는 것이 결정이지 타이핑이 아니기 때문입니다.

스크립트로 돌리신다면 `--grant-vault` 또는 `--no-grant-vault` 로 미리 답할 수 있습니다.
나중에 바꾸려면 컨테이너 안에서 `valetfs setup-claude` 를 돌리거나
`~/.claude/settings.json` 을 고치면 됩니다.

비밀값이 에이전트의 전사본을 거치지 않고 명령에 닿는 방법은
[secrets.md](secrets.md) 에 있습니다.

## 이것이 아닌 것

- **클라우드 대체재가 아닙니다.** 위의 굵은 줄을 보십시오.
- **GPU 장비가 아닙니다.** 호스팅 모델을 부르는 에이전트를 위한 작업환경이고, 로컬
  추론을 구성하지는 않습니다.
- **제 기계 그대로가 아닙니다.** 이것을 뽑아낸 환경에는 에이전트가 모는 브라우저와
  터널, 그 밖에 옮길 수 없는 호스트 고유의 것들이 더 있습니다. 여기서는 의도적으로
  범위 밖에 두었습니다.
- **저 말고 아무도 감사하지 않았습니다.** 돌리기 전에 `docker/Dockerfile` 을
  읽으십시오. 60줄이고, 짧게 둔 이유가 그것입니다.
