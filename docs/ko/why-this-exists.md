# 왜 만들었나

English: [../why-this-exists.md](../why-this-exists.md)

README 비교표의 각 항목에 대한 근거입니다.

## 내가 통제하는 하드웨어에서 실행

클라우드 작업환경이 몇 초 만에 시작되는 것은 서비스 제공자의 하드웨어에서 실행되기
때문입니다. 그래서 작업환경이 무엇에 접근할 수 있는지도 제공자가 정하고, 예고 없이 바꿀 수
있습니다. 직접 관리하는 기계에서는 이 범위를 사용자가 설정합니다.

## 세션이 끝나도 맥락이 남는다

호스팅 메모리는 무엇을 보관할지 선택하며, 보관하는 내용도 대개 요약입니다. 파일
디렉터리에는 작성한 내용이 삭제하기 전까지 그대로 남습니다.

권한처럼 눈에 띄는 항목보다 뒤로 밀리기 쉽지만, 매일 작업할 때 체감 차이가 가장 큰
항목입니다. 저장소만 읽고 시작하는 에이전트와, 이전 세션의 메모와 결정까지 함께 읽는
에이전트는 다르게 동작합니다.

## 데스크톱·브라우저 제어

호스팅 에이전트는 브라우저와 데스크톱 접근을 제한합니다. 그럴 만한 이유가 있습니다. 직접
관리하는 기계에서는 이 권한을 사용자가 설정하며, 잘못 설정하는 경우도 포함됩니다. 통제권을
갖는 대가이지 통제권의 장점은 아닙니다.

## 자격 증명과 권한

나머지 설계가 이 항목에서 나옵니다.

에이전트에게 서비스 접근 권한을 주는 일반적인 방법은 에이전트가 읽을 수 있는 위치에 키를
두는 것입니다. 환경 변수, `.env` 파일, git remote URL 에 포함된 토큰이 그렇습니다. 문제는
읽는 동작 자체입니다. 에이전트가 키를 사용하기 위해 한 번 읽으면 전사본에 사본이 생깁니다.
원본을 삭제해도 사본은 남고, 사본은 폐기할 수 없습니다.

부주의해야만 생기는 일이 아닙니다. git remote URL 에 포함된 토큰은 에이전트가 처음
`git remote -v` 를 실행하는 순간 전사본에 기록됩니다. 자격 증명을 노출하는 명령으로 여기지
않는 일상적인 명령입니다.

[ValetFS](https://github.com/WinM2M/valet-fs) 는 키를 폰에 보관하고, 폰이 허용하는
동안에만 메모리로 기계에 전달합니다. `valetfs exec` 는 값을 자식 프로세스에 전달하므로
에이전트는 명령을 작성하되 키는 받지 않습니다.

```sh
valetfs exec fs:/keys/aws.env -- aws s3 ls s3://bucket
```

설치기는 공개된 SHA-256 을 확인한 뒤 설치합니다. 이 체크섬은 바이너리와 같은 릴리스에서
제공되므로 손상된 다운로드는 확인할 수 있지만 출처는 확인할 수 없습니다. 출처 확인용 cosign
명령은 README 에 있습니다.

부트스트랩은 에이전트가 승인 없이 `valetfs exec` 를 실행하도록 허용하기 전에 묻습니다.
설정 적용은 스크립트가 하지만, 에이전트에게 금고 상시 접근을 줄지는 운영자가 결정합니다.

ValetFS 는 이 저장소와 같은 저자가 공개했으며, 제3자 보안 감사를 받지 않았습니다.

## 작업 중에 UI 를 만들어 붙인다

인터페이스 코드만 작성할 수 있는 에이전트는 매 반복마다 사람이 결과를 확인하고 무엇이
잘못됐는지 설명해 줘야 합니다. 만든 화면을 직접 띄워 확인할 수 있는 에이전트에게는 이 전달
과정이 필요하지 않습니다.

## 내가 자는 동안에도 돈다

이 항목에서는 클라우드가 유리합니다. 집에 있는 컴퓨터의 전원이 꺼지거나 네트워크가 끊겨도,
노트북 덮개를 닫아도 호스팅 에이전트는 계속 실행됩니다. 호스트를 계속 켜 두고 cron 과
컨테이너 재시작 정책을 설정하면 대부분의 경우를 처리할 수 있지만, 데이터센터가 제공하는
가용성과 같지는 않습니다.

반드시 실행돼야 하는 예약 작업에는 클라우드를 사용해 주세요. 이 문서의 어떤 내용도 그에
반대하지 않습니다.

## 데이터가 둔 자리에 남는다

개인 사용자에게는 체감되는 것보다 영향이 작습니다. 계약이나 현지 법이 타인의 데이터를
처리할 수 있는 위치를 제한할 때 의미가 생깁니다.

## 비용을 예측할 수 있다

기계를 직접 보유하면 작업환경 비용을 추정하기 쉬워집니다. 다만 하드웨어는 고장 나고 전기도
무료가 아닙니다. 모델 API 사용량은 어느 쪽이든 사용한 만큼 과금됩니다. 이 항목은 모델이
아니라 작업환경에 대한 것입니다.

## 이게 맞지 않는 사람

AI 비서를 주에 몇 번 사용한다면 브라우저 탭이 더 나은 선택입니다. 여기 드는 설정 비용은
매일 사용할 때에만 의미가 있습니다.
