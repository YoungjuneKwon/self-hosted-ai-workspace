# 왜 만들었나

English: [../why-this-exists.md](../why-this-exists.md)

README 표의 각 줄에 대한 근거입니다.

## 내가 통제하는 하드웨어에서 실행

클라우드 작업환경이 몇 초 만에 뜨는 것은 공급자 하드웨어에서 돌기 때문입니다. 그래서
무엇에 닿을 수 있는지도 공급자가 정하고, 예고 없이 바꿀 수 있습니다. 자기 기계에서는 그
한계를 자기가 정합니다.

## 세션이 끝나도 맥락이 남는다

호스팅 메모리는 무엇을 남길지 스스로 정하고, 남기는 것도 대개 요약입니다. 파일 디렉터리는
쓴 그대로를 누가 지울 때까지 보관합니다.

권한처럼 눈에 띄는 항목 옆에 두면 과소평가하기 쉬운 줄입니다. 실제로는 매일의 작업을 가장
많이 바꾸는 줄입니다. 저장소에서 시작하는 에이전트와, 저장소에 더해 이미 합의해 둔 것까지
들고 시작하는 에이전트는 다른 도구입니다.

## 데스크톱·브라우저 제어

호스팅 에이전트는 브라우저와 데스크톱 접근을 제한합니다. 그럴 만한 이유가 있습니다. 자기
기계에서는 그 권한을 자기가 고르고, 잘못 고르는 것도 포함됩니다. 장점으로 포장하지 않고
거래 조건 그대로 적습니다.

## 자격 증명과 권한

나머지 설계가 따라 나오는 줄입니다.

에이전트에게 서비스 접근을 주는 보통의 방법은 에이전트가 읽을 수 있는 자리에 키를 두는
것입니다. 환경 변수, `.env` 파일, git remote URL 에 박은 토큰. 문제는 읽는다는 것
자체입니다. 에이전트가 키를 쓰려고 한 번 읽으면 그 사본이 전사본에 남습니다. 원본을 지워도
사본은 지워지지 않고, 폐기할 수도 없습니다.

부주의해야만 생기는 일이 아닙니다. git remote URL 에 박힌 토큰은 `git remote -v` 한 번에
전사본으로 넘어갑니다. 에이전트가 일상적으로 치는 명령이고, 누구도 그것을 유출 행위로
생각하지 않습니다.

[ValetFS](https://github.com/WinM2M/valet-fs) 는 키를 폰에 두고, 폰이 허용하는 동안
메모리로만 기계에 제공하는 방식으로 이 문제를 다룹니다. `valetfs exec` 는 값을 자식
프로세스에 넘기므로 에이전트는 명령을 쓰되 키는 보지 못합니다.

```sh
valetfs exec fs:/keys/aws.env -- aws s3 ls s3://bucket
```

설치기는 공개된 SHA-256 을 확인한 뒤 설치합니다. 그 체크섬은 바이너리와 같은 릴리스에서
오므로 다운로드가 깨진 것은 잡아도 출처를 확립하지는 못합니다. 그 용도의 cosign 명령은
README 에 있습니다.

부트스트랩은 에이전트에게 `valetfs exec` 무프롬프트 권한을 주기 전에 물어봅니다. 설정을
적용하는 일은 스크립트가 해도 되지만, 금고에 상시 접근을 허용할지는 사람이 정해야 합니다.

ValetFS 는 이 저장소와 같은 저자가 공개한 것이고, 제3자 보안 감사를 받은 적이 없습니다.

## 작업 중에 UI 를 만들어 붙인다

인터페이스 코드만 쓸 수 있는 에이전트는 매 반복마다 사람이 결과를 보고 무엇이 잘못됐는지
말로 옮겨 줘야 합니다. 만든 것을 띄워서 직접 확인할 수 있는 에이전트는 그 중계 없이 고리를
닫습니다.

## 내가 자는 동안에도 돈다

이 줄은 클라우드가 이깁니다. 집에 있는 기계의 전원이나 네트워크나 노트북 덮개가 멈춰도
호스팅 에이전트는 계속 돕니다. 켜 두는 호스트에 cron 과 컨테이너 재시작 정책을 걸면 대체로
버티는데, 「대체로」는 데이터센터가 말하는 가동률이 아닙니다.

놓치면 안 되는 예약 작업은 클라우드의 몫입니다. 여기 적힌 어떤 것도 그에 반대하지 않습니다.

## 데이터가 둔 자리에 남는다

개인에게는 들리는 것만큼 중요하지 않습니다. 계약이나 관할권이 남의 자료를 어디서 처리할 수
있는지 제한할 때부터 중요해집니다.

## 비용을 예측할 수 있다

기계를 직접 갖고 있으면 작업환경 비용은 가늠하기 쉬워집니다. 다만 하드웨어는 고장 나고
전기도 공짜가 아닙니다. 모델 API 사용량은 어느 쪽이든 종량제입니다. 이 줄은 모델이 아니라
작업환경에 대한 것입니다.

## 이게 맞지 않는 사람

주에 몇 번 쓰는 정도라면 브라우저 탭이 더 나은 도구입니다. 여기 드는 세팅 비용은 매일 쓸
때에만 회수됩니다.
